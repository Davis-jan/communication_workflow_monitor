# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2026-01-15

### Added
- Initial release of n8n Follow-Up Checker workflow
- Visual workflow diagram with interactive node selection
- Complete n8n JSON workflow for import
- Step-by-step setup guide
- Node configuration details panel
- Support for Gmail, WhatsApp, and Call Log integrations
- AI-powered analysis using GPT-4
- Time-gated notifications (06:00 AM)
- Google Sheets integration for data tracking
- Telegram and Slack notification support
- Copy and download JSON functionality
- Responsive dark-themed UI
