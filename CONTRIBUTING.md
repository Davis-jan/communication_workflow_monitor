# Contributing to n8n Follow-Up Checker

Thank you for your interest in contributing! This document provides guidelines and information for contributors.

## 🚀 Getting Started

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/n8n-followup-checker.git
   cd n8n-followup-checker
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Create a branch for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## 📝 Development

- Run the dev server: `npm run dev`
- Build for production: `npm run build`
- Type check: `npm run typecheck`

## 🔧 Code Style

- Use TypeScript for all new files
- Follow the existing component structure
- Use Tailwind CSS for styling (no custom CSS files)
- Keep components small and focused

## 📦 Pull Request Process

1. Update the README.md if your changes affect documentation
2. Ensure your code builds without errors (`npm run build`)
3. Write clear commit messages
4. Reference any related issues in your PR

## 🐛 Reporting Bugs

Use the bug report template when creating issues. Include:
- Steps to reproduce
- Expected behavior
- Actual behavior
- Your environment (n8n version, OS, browser)

## 💡 Feature Requests

We love new ideas! Open a discussion or issue with:
- Clear description of the feature
- Use case / problem it solves
- Suggested implementation (optional)
